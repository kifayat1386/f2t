# KhamarBari Live (powered by FarmLive BD tech)

A premium farm-to-door live-commerce asset exchange for Bangladesh.

## Monorepo
Turborepo + pnpm workspaces.

## Getting Started

1. Use Node v22 (`nvm use`)
2. `pnpm install`
3. `cp .env.example .env`
4. `docker compose -f infra/docker-compose.yml up -d`
5. `pnpm dev`
